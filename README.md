# Virat Kohli Career Stats Analysis

## Overview
This repository contains a dataset detailing Virat Kohli's batting performance across Test, ODI, and T20I formats from 2010 to 2025. The dataset includes key metrics such as runs, strike rates, averages, highest scores, boundaries, and dot ball percentages, offering insights into his consistency and performance trends.

## Dataset Fields
The dataset consists of the following fields:
- **Year**: Year of the performance.
- **Format**: Cricket format (Test, ODI, T20I).
- **Innings**: Number of innings played.
- **Runs**: Total runs scored.
- **Balls**: Total balls faced.
- **Outs**: Number of times dismissed.
- **Avg**: Batting average.
- **SR**: Strike rate.
- **HS**: Highest score in the year.
- **50**: Number of half-centuries.
- **100**: Number of centuries.
- **4s**: Number of fours hit.
- **6s**: Number of sixes hit.
- **Dot %**: Percentage of dot balls faced.

## Key Insights
- Kohli's performance peaked in ODI cricket between 2016-2018, with high averages and strike rates.
- His Test performances have been consistent, with multiple years crossing 1,000+ runs.
- His T20I strike rate has remained above 120 for most of his career.
- Recent performances (2024-2025) indicate a dip in form across all formats.

## Usage
This dataset can be used for:
- Cricket analytics and visualization.
- Performance trend analysis of Virat Kohli.
- Machine learning models for predicting player form.
